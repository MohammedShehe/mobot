# MO (mobot)

Human-robot assistant on Groq. Built by MO11 (molittle.fourbrothers.online).

Run: `flutter pub get && flutter run --dart-define=GROQ_API_KEY=...`

Settings: Groq key + model, OpenWeather, News API, Calendar, Home Assistant,
Music app, voice (male/female, choose voice, replies always / after voice input / off),
hands-free wake word. Chat history is saved on-device only (no server).
